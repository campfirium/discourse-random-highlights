## New

- Grouped highlights can include headings, lists, and multiple paragraphs as one excerpt using `[wrap=random-highlight]...[/wrap]`.

## Improved

- Random highlights follow the native mobile topic-row layout.
- Highlight loading runs only on Latest, shares concurrent requests, and limits each load to five candidate topics within ten seconds.

## Fixed

- Source content is fetched again before display; old persistent excerpt caches are removed instead of reused after access changes.
- Updated source text and titles appear on subsequent visits to Latest.
- Temporary tag request failures can be retried on the next visit.
- The random row appears only on the global Latest list and keeps desktop columns aligned during bulk selection.
- Empty highlight color settings fall back to the shipped defaults.
